# Test Specification — RRD Materialized Rollups and WASM Time-Series UDFs

> Generated by blueprint artifacts.
> Last updated: 2026-05-20

## Overview

This test specification covers the feature path from CQL DDL through storage
materialization, WASM UDF loading/execution, virtual table observability,
subscriptions, and examples. It is intentionally layered so implementation can
land through TDD without waiting for cluster-wide end-to-end tests first.

## Traceability Summary

- FMEA rows with RPN >= 200 have at least one Critical test:
  FM1, FM3, FM4, FM6.
- Threats T1, T2, T4, T8, T9, T10, and T12 map to unit, integration, or
  system tests.
- DSM boundaries have contract tests for registry, queue provider, worker
  target encoding, UDF identity, and subscriptions.
